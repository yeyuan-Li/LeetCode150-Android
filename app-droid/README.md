# LeetCode 150 打卡 · Android 版

一个纯离线的刷题打卡 App。150 道 LeetCode Top Interview 题，6 个页面，数据只存在本机。

**这个版本存在的唯一理由**：微信小程序在平台层面禁止唤起外部浏览器，`wx.setClipboardData` 是它唯一能做的事。Android App 没有这个限制——点「打开题目」直接跳系统浏览器，不用复制粘贴。

---

## 一、安装（30 秒）

**产物位置**：`app-droid/out/lc150-tracker.apk`（76 KB）

1. 把 APK 传到手机：微信「文件传输助手」发给自己 / QQ / 数据线拷进手机
2. 在手机上点开这个文件
3. 系统提示「禁止安装未知来源应用」时，按提示允许一次（这是 Android 对所有非应用商店 APK 的标准拦截，不是这个应用的问题）
4. 装完桌面出现图标，名字是 **LeetCode 150**

**系统要求**：Android 7.0（API 24）及以上。

**权限**：只有一个 `VIBRATE`（选题/完成时的轻震动）。**没有申请网络权限**——不是"不联网"，是系统层面就没有联网能力，飞行模式下所有功能照常。

> ⚠️ iOS 装不了。想给 iPhone 用只有两条路：网页版（加到主屏幕）或上架 App Store（需要付费开发者账号 + 审核）。

## 二、分享给别人

直接把 `out/lc150-tracker.apk` 这个文件发过去就行，对方按上面步骤装。

每个人的做题记录、备注、复习排期都存在各自手机的本地存储里，互相独立，不需要账号、不需要服务器。

**注意**：APK 用的是自签名证书（`keystore/lc150.jks`），所以对方安装时同样会看到"未知开发者"提示。这是正常的，任何非商店渠道的 APK 都这样。

## 三、功能

| 页面 | 能做什么 |
|---|---|
| **今日** | 连续打卡天数、今日完成 x/目标、待复习红点；按顺序从没做过的题里取当日题单 |
| **题库** | 150 题按 8 个阶段分组折叠；按状态/难度筛选，搜题号或题名 |
| **详情** | **一键打开题目**、25 分钟倒计时（Hard 提示 40 分钟上限）、三档自评、备注、复习排期与历史 |
| **复习** | 按到期日排序，逾期在前，标出第几轮 |
| **进度** | 总完成率圆环、8 个阶段的完成率与独立率、阶段解锁状态 |
| **我的** | 每日目标、深/浅主题、考试模式、导出/导入、清空 |

### 复习排期规则（写死的口径）

| 自评档位 | 排期 |
|---|---|
| 独立（没看提示自己 AC） | D+7 |
| 提示（看了提示/部分题解） | D+3、D+7 |
| 题解（抄了题解） | D+1、D+3、D+7 |

复习后可以重新自评，按新档位从当天重新排后续轮次。

### 阶段解锁规则

每个阶段「独立完成」达到 **80%** 才解锁下一阶段。没解锁时进度页显示「暂未解锁 · 还差 N 题」。

## 四、数据与备份（换手机就靠这个）

所有数据存在 WebView 的 `localStorage` 里，**卸载应用 = 数据丢失**。

### 换新手机 / 重装后接着刷

```
老设备：我的 → 导出数据 →「保存为文件」
          ↓  系统弹出保存框，选「下载」或网盘，得到 lc150-backup-2026-10-26.json
传输：  文件管理器长按该文件 → 分享 → 微信文件传输助手 / QQ / 网盘
          ↓
新设备：我的 → 导入数据 →「选择文件导入」→ 选中这个文件
          ↓  提示「已导入 42 题记录」，进度、备注、复习排期全部接上
```

全程走**系统文件选择器**（Android 的 SAF），所以：

- 不申请任何存储权限，安装时不会出现「访问照片和文件」的授权弹窗
- 应用自身不联网，备份文件通过你已有的工具（微信、网盘、数据线）传
- 文件是纯 JSON，可以打开看一眼，也可以存进任何网盘

### 导入是安全的

- **先校验、后写入**：字段类型、题号是否存在、自评档位、复习轮次、日期格式——任何一项不合法就直接报错，现有数据一个字都不改
- **可以反悔**：导入前会自动留一份旧数据快照。误导入（比如把新设备的空备份导进老设备）后，在「导入数据」面板里点「撤销上次导入」就能回到导入前状态
- **清空要两次确认**，且清空时连同快照一起清掉

### 另外两条退路

| 场景 | 做法 |
|---|---|
| 手机没有文件选择界面（极少数定制 ROM） | 导出时点「改为一键复制文本」，把 JSON 粘到备忘录；导入时点「改为粘贴文本」 |
| 想和小程序版互换数据 | 两边格式完全一致（同一份 `exportJson`），小程序导出的文本可以直接粘到 APK 里导入，反之亦然 |

## 六、自己重新构建

### 环境要求（本机已装好）

| 组件 | 版本 | 位置 |
|---|---|---|
| JDK | 21 | `C:\Program Files\Java\jdk-21` |
| Android SDK | build-tools 36.0.0 + platforms;android-34 | `D:\DEVELOP\Android\Sdk` |
| Node | 22（构建脚本用，不需要运行时） | 已在 PATH 外的固定路径，见 `build.sh` |

**不需要 Gradle，不需要 Android Studio。**

### 构建

```bash
cd app-droid
bash build.sh
```

产物：`out/lc150-tracker.apk`

首次运行会自动生成签名密钥 `keystore/lc150.jks`。**这个 keystore 要保留**——后续版本必须用同一个签名才能覆盖升级，换了签名只能卸载重装。

签名口令**不写进仓库**：`build.sh` 优先读环境变量 `LC150_KS_PASS`，其次读本地文件 `keystore/keystore.properties`：

```properties
storePassword=你的口令
keyPassword=你的口令
```

> `keystore/`（含 `.jks` 与 `keystore.properties`）已被 `.gitignore` 排除，不会上传到 GitHub。
> 克隆本仓库后首次构建需要自己准备口令（见上方），否则 `build.sh` 会明确报错退出。
> 用它构建出来的 APK 无法覆盖安装 GitHub Releases 里那份（签名不同），需要先卸载旧版。
> 想在自己的机器上连续升级，只需要在本地留住 `keystore/`，并把它单独备份到密码管理器或私密网盘。

### 构建流程做了什么

```
[1] tools/bundle.js   把 utils/{date,bank,store}.js + data/questions.js 打成 bundle.js
[2] 拷贝到无中文路径的临时目录（aapt2 处理不了中文绝对路径）
[3] aapt2 compile/link  编译资源、打包 assets
[4] javac --release 8   编译 MainActivity（classpath 指向 android.jar）
[5] d8                  转成 classes.dex
[6] tools/pack.py       把 dex 塞进 apk
[7] zipalign + apksigner 对齐、签名
```

## 八、已知限制

1. **iOS 不可用**：APK 只能装在 Android 上。
2. **跨设备不同步**：没有账号和后端（这是刻意的），换手机靠「导出文件 → 传输 → 导入文件」，见第四节。
3. **卸载丢数据**：`localStorage` 会随应用卸载被清除，重要记录先导出。
4. **不能直接提交代码**：点「打开题目」跳到的是浏览器里的 leetcode.cn 网页版，看题、写代码、提交都在那边完成，本应用只负责记录与排期。
5. **题面不在应用内**：只有题号、标题、难度、标签和链接，不抓取题干（省体积，也避免题目更新后版本不一致）。
6. **自签名**：不是应用商店包，安装时会有未知来源提示。
7. **深色/浅色切换会让状态栏同步变色**，但部分国产 ROM 的自定义状态栏可能忽略颜色设置。
8. **应用名是「LeetCode 150」**，与 LeetCode 官方无关，纯个人工具。

## 九、技术实现要点

**为什么用 WebView 而不是原生 UI**

6 个页面的交互（列表、折叠、筛选、计时器、表单）用原生 View 写要几千行，WebView + HTML 一百多行 CSS 就够，而且和小程序版共用同一套业务逻辑。APK 76 KB，启动无白屏。

**为什么不用 `file://` 加载页面**

`file://` origin 下 `localStorage` 在部分 WebView 版本上不可靠。改用虚拟域名 `https://appassets.local`，由 `shouldInterceptRequest` 从 assets 读取文件返回——这等价于官方 `WebViewAssetLoader` 的做法，但少一个 AndroidX 依赖。这样 origin 是正常的 https，存储行为与线上网页一致。

**一键跳浏览器怎么实现的**

JS 里 `NativeBridge.openUrl(url)` → `window.Android.openUrl()` → Java 侧 `startActivity(new Intent(ACTION_VIEW, uri))`。同时 `shouldOverrideUrlLoading` 兜底：页面里任何非本地链接都会交给系统处理，不会在 WebView 里打不开。

**备份为什么不用存储权限**

导出走 `Intent.ACTION_CREATE_DOCUMENT`、导入走 `ACTION_OPEN_DOCUMENT`（都属 Android 的 SAF）。
系统弹出自己的保存/选择界面，用户授权后应用只拿到那一个文件的临时读写句柄，
所以既不用 `WRITE_EXTERNAL_STORAGE`，也不用 `FileProvider`（那需要引 androidx，
而本工程是零依赖手工构建的）。

WebView 里的 `Blob` + `a[download]` 在 Android WebView 上会被直接丢弃（没有下载管理器接管），
这是"必须走原生"的原因。

**构建踩过的两个坑**（写在注释里了）

- `aapt2` 处理不了含中文的绝对路径 → 构建在系统临时目录里做，全程用相对路径
- build-tools 34 的 `d8` 在 JDK 21 下编译匿名内部类会 NPE 崩溃 → 升到 build-tools 36，并绕过 `.bat` 直接 `java -cp d8.jar`

## 十、版本记录

### v1.2.1（当前，versionCode 5）

**修复：每日目标 3 → 5 → 3 之后，今日题单停在 5 题**

`store.planToday()` 里只有「数量不足就补题」这一条分支，没有相反的分支：

```js
// 旧代码
if (nos.length < target) { /* 补题 */ }
```

所以 3 → 5 会把题单补到 5 个，再切回 3 时 `nos.length(5) > target(3)`，函数什么也没做，
直接返回缓存的 5 题。今日页的分母已经变成 `/3`，列表却还是 5 行，看起来就像设置没生效。

修复是补上收缩分支 `shrinkPlan()`，并且**已完成的题优先保留**——只在后面按顺序补足名额：

- 已完成 2 题、目标从 5 调到 3 → 保留那 2 题 + 原顺序里最前面 1 题未完成的，不会把做过的踢出列表
- 收缩后仍按原顺序输出，题单不会跳序
- 再切回 5 时按原逻辑补题，可逆

补了 `tests/verify-store.js`（+9 项逻辑断言）和 `tools/clicktest-target.js`
（18 项真实点击：3→5→3→5 走一遍，同时校验 DOM 行数、`lc150:plan` 缓存长度、
`lc150:settings` 和按钮高亮四处是否一致）。合计 239 项。

小程序版共用同一份 `utils/store.js`，同步修复。

### v1.2.0（versionCode 4）

**换机迁移改成文件级：导出成 .json 存盘，导入时从文件选**

之前只能「一键复制文本 + 粘贴」，在手机上复制几万字符的 JSON 很别扭，
传给新手机还得靠聊天记录。现在：

- 导出 →「保存为文件」→ 系统保存框，选「下载」或网盘
- 导入 →「选择文件导入」→ 系统文件列表，选中即恢复
- 两条都零权限（SAF），复制/粘贴保留为退路
- 导入前自动留快照，误导入后能「撤销上次导入」
- 导入校验拆出 `validateImport()`：先校验、确认能过才留快照、再写入，
  于是导入失败既不动数据，也不会把上一次的撤销点冲掉

顺带修了一个真 bug：在新设备（空数据）上导入后点撤销会失败，
因为 `progress` 为空的快照过不了 `importJson` 的「不能为空」校验。
快照是本应用自己生成的，改为不走导入校验、直接按 normalize 恢复。

同时补了两层测试：`tests/verify-backup.js`（40 项逻辑断言）和
`tools/clicktest-backup.js`（44 项真实点击），合计从 128 项涨到 212 项。

**取舍**：评估过的账号 / 云同步方案最终没有采用，应用保持零联网
（不申请 `INTERNET` 权限），跨设备迁移只走「导出文件 → 导入文件」这一条路。

### v1.0.1（versionCode 2）

**修复：点底部 tab 没反应（题库 / 进度 / 我的打不开）**

`index.html` 里 `#app` 和 `#tabbar` 是兄弟节点，但点击事件委托只绑在了 `#app` 上，
